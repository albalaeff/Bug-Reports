# [Xiaomi Redmi 15][Android 16] Premier League radio remains stuck in loading state <br>
Device: Xiaomi Redmi 15

## Steps to reproduce:
1. Open the OneFootball application.<br>
2. Tap **Games** in the bottom navigation menu.<br>
3. Scroll down to the **Premier League** section.<br>
4. Tap **Premier League**.<br>
5. Tap the radio icon in the upper-right corner.<br>
6. Tap the **Play** button.<br>

## Expected result:
The radio stream should start playing after the user taps the **Play** button.

## Actual result:
The radio player remains stuck in a loading state indefinitely, and the radio stream does not start.

## Type: 
Functional

## Severity: 
Medium-High
